# A Little Gallery of You

A simple photo-first gallery built with plain HTML, CSS and vanilla JavaScript.

## Run it
Open `index.html` in your browser. For best results, use VS Code Live Server.

## Add your photos
Put your own photos into these folders and name them in order:

- `images/hero.jpg` — the large landing-page photo
- `images/cute/01.jpg`, `02.jpg`, `03.jpg` ...
- `images/hot/01.jpg`, `02.jpg`, `03.jpg` ...
- `images/babyyyyy/01.jpg`, `02.jpg`, `03.jpg` ...
- `images/favourites/01.jpg`, `02.jpg`, `03.jpg` ...

The starter is configured for 75 photos in each collection (300 total). If your categories have different counts, edit the `count` values in `script.js`.

The preview cards use the first photo in each collection. If a photo is missing, a white and baby blue placeholder appears.

## Personalize it
- Edit the greeting and section copy in `index.html` or `script.js`.
- Replace the placeholder text in the letter modal in `index.html`.
- The theme is white and baby blue. Change colors and layout in `style.css`.

## Privacy
This is a static website. Photos stay in the project folder and are not uploaded anywhere by this code. If you publish the site online, use a private hosting/access setup and only include photos your girlfriend is comfortable sharing.
